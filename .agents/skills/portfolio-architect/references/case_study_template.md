# Blueprint Case Study Portofolio Standar HRD & ATS (Google XYZ / STAR)
> **Tujuan:** Menghasilkan deskripsi proyek teknis yang langsung memikat recruiter dan memiliki kata kunci relevan untuk algoritma ATS.

---

## 1. FORMULA FORMAL PROYEK TEKNIS
Setiap kartu atau modal studi kasus proyek idealnya memuat 5 elemen arsitektur:

### A. Meta Identitas Proyek
* **Nama Proyek:** Ringkas, profesional, dan mencerminkan domain (misal: *Enterprise Multi-Tenant ERP*, *High-Throughput ETL Migration Engine*).
* **Tagline 1 Baris (Google XYZ):** *"Menyelesaikan [Problem X] dengan menerapkan [Tech Y], menghasilkan [Impact Z]"*.
* **Tautan Eksternal:**
  * 🌐 `Live Demo` (jika sistem publik) atau `Interactive Walkthrough / Video Demo`
  * 💻 `GitHub Repository` (dengan badge status: `Public`, `Core Architecture Only`, atau `Client Confidential`).

### B. Taksonomi Kata Kunci ATS (Tech Stack Pills)
* **Kategori Backend:** PHP 8.x, Laravel 11, Node.js, Go, Python.
* **Kategori Database & Data:** MySQL, PostgreSQL, Redis, Elasticsearch, ETL Pipeline.
* **Kategori Frontend & UI:** Tailwind CSS, GSAP, Svelte 5, React, TypeScript.
* **Kategori Infra / Security:** Docker, OAuth 2.0 / Passport, REST API, CI/CD, Nginx.

---

## 2. FORMAT KONTEN: STAR FRAMEWORK (4 BLOK RINGKAS)

```markdown
### [Nama Proyek]: [Spesialisasi / Domain Proyek]
> **Metrik Kunci:** ⚡ Migrasi 12.000+ data dalam < 15 menit | 🔒 0 celah keamanan (OWASP ASVS compliant)

#### 1. Situation & Challenge (Tantangan Nyata)
Jelaskan latar belakang bisnis/teknis dalam 2-3 kalimat:
- Masalah performa, fragmentasi database lama, beban manual, atau sistem yang lambat.
- Batasan infrastruktur atau waktu penyelesaian.

#### 2. Architectural Solution (Solusi Arsitektur)
Jelaskan strategi rekayasa yang dipilih:
- Mengapa memilih stack tersebut? (contoh: *Menggunakan Laravel Passport untuk token scoping dan Redis untuk caching query kompleks*).
- Desain skema basis data dan pengamanan endpoint.

#### 3. Quantifiable Impact & Results (Dampak Terukur)
Tampilkan 2-3 poin numerik konkret (Google XYZ):
- ✅ **Skalabilitas:** Mampu menangani `10.000+` transaksi harian tanpa degradasi latency.
- ✅ **Efisiensi:** Mengurangi waktu pemrosesan laporan dari `45 menit` menjadi `2 menit` (peningkatan 95%).
- ✅ **Integritas Data:** Berhasil memvalidasi dan memigrasi `12.500+` data warisan dengan `100% data consistency`.

#### 4. Kredensial & Tautan
- [Live Demo](https://...)
- [Source Code (GitHub)](https://github.com/...)
```
